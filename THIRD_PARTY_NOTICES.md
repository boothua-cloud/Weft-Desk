本项目自身以 MIT 许可发布，见 [LICENSE](LICENSE)。

编译产物中包含了下列第三方组件，各自的版权与许可声明保留于此，以满足其分发要求。

## 组件清单

| 组件 | 许可 | 版权持有者 |
|---|---|---|
| `tailscale.com` | BSD 3-Clause | Tailscale Inc. |
| `github.com/tailscale/wireguard-go` | MIT | WireGuard LLC |
| `github.com/wailsapp/wails/v3` | MIT | Lea Anthony |
| `github.com/zalando/go-keyring` | MIT | Zalando SE |
| `golang.org/x/sys` | BSD 3-Clause | The Go Authors |
| `golang.org/x/text` | BSD 3-Clause | The Go Authors |
| `modernc.org/sqlite` | BSD 3-Clause | The Sqlite Authors |
